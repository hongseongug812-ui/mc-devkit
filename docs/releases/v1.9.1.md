# MC DevKit 1.9.1

기존 서버 종류와 Forge·NeoForge, 승인 배포·게임 시작 전 모드 적용 기능을 유지하면서 앱 자동 업데이트를 개선했습니다.

- 앱 시작 시와 15분마다 새 버전을 확인하고 백그라운드로 자동 다운로드합니다.
- 다운로드 완료 후 서버·게임·모드 적용·빌드·촬영 모드·터널 작업이 끝나고 앱 창이 트레이에 있으면 자동 설치 후 재실행합니다.
- 설치 전에 모드 적용과 서버 관리 작업을 정리합니다. 사용 중인 화면에서는 자동으로 앱을 닫지 않습니다.
- 앱 완전 종료 시 다운로드된 업데이트를 자동 설치하는 동작도 유지합니다.

1.9.0 이하 앱은 한 번 완전 종료하거나 업데이트 재시작을 선택해 1.9.1을 설치하면 이후 이 자동 업데이트 흐름을 사용합니다.
