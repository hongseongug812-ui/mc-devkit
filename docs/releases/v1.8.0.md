# MC DevKit 1.8.0 — Creator Studio

콘텐츠 제작팀이 서버와 참가자 모드를 함께 관리할 수 있도록 화면을 개편하고 모드팩 자동 동기화를 추가했습니다.

## 주요 변경

- 서버 카드, 넓은 서버 설정 화면, 세부 설정 토글, 모드팩 배포와 참가자 관리 UI를 새롭게 정리했습니다.
- 서버·Minecraft 버전별 모드팩을 배포하고 공식 런처·CurseForge·Modrinth의 게임 폴더에 자동 동기화할 수 있습니다.
- 서버의 공용 모드를 한 번 교체하면 참가자가 변경을 받도록 원본 폴더 감시와 파일 규칙을 지원합니다. 앱 실행 중 15초마다 배포를 확인합니다.
- SHA-256 파일 검증, 교체 전 백업, 개인 모드 충돌 보호, 게임 실행 중 적용 보류, 중단된 작업 복구를 추가했습니다.
- 서버 종류별 버전 목록 새로고침, Paper 공식 안정 빌드와 체크섬 검증, Minecraft 26.x의 Java 25 자동 준비를 개선했습니다.
- 소유자 토큰 노출을 제거하고 관리 API 권한 검사를 보강했습니다. 신규 멤버는 호스트가 권한을 부여하기 전까지 서버를 제어할 수 없습니다.
- 앱에서 수동 업데이트 확인을 사용할 수 있습니다.

## 시작 방법

호스트는 서버 프로필의 **모드팩** 탭에서 원본 폴더와 배포 파일 규칙을 지정하고 **자동 배포**를 켠 뒤 참가 링크를 공유하세요. 참가자는 자신의 MC DevKit에서 **서버 참가**를 누르고 런처의 서버 전용 게임 폴더를 연결하면 됩니다.

호스트 앱과 공유 주소가 실행 중이어야 다운로드할 수 있습니다. Minecraft용 playit 주소와 DevKit 모드팩 공유용 HTTP(S) 주소는 서로 다릅니다. 임시 공유 터널 주소가 바뀌면 새 참가 링크로 다시 연결하세요.

게임 버전이 바뀌면 모드 자체는 해당 버전용으로 빌드해야 하며, 런처의 게임 버전과 로더는 별도로 설치해야 합니다. 서버 전용 모드는 참가자 배포 규칙에서 제외하세요.

[모드팩 동기화 사용법](https://github.com/hongseongug812-ui/mc-devkit/blob/v1.8.0/docs/modpack-sync.md)

## 업데이트

기존 설치 버전은 앱을 다시 실행하면 새 릴리스를 확인하고 자동으로 다운로드합니다. 다운로드 완료 안내에서 **재시작**을 선택하세요. **나중에**를 선택하면 다음 완전 종료 때 설치됩니다. 창의 X 버튼은 트레이로 숨기는 동작입니다.

설치 파일, 차등 업데이트용 blockmap, `latest.yml`을 함께 제공합니다.

## 검증

자동 테스트 19개, 실제 HTTP 모드팩 다운로드·교체, 공식 버전 API, 패키징된 앱의 화면 렌더링·프로필 불러오기·설정 저장 검증을 통과했습니다. 다른 실제 참가자 PC의 게임 실행과 인터넷 환경은 별도로 확인해야 합니다.
