# MC DevKit 1.9.0

콘텐츠 제작팀을 위한 승인 배포와 게임 시작 전 자동 적용을 추가했습니다.

- **Forge · NeoForge 독립 서버 추가**: 기존 Paper, Fabric, Vanilla, Arclight, Cardboard를 모두 유지합니다. 공식 Minecraft·로더 버전 목록, 정확한 버전 선택, 설치 파일 체크섬 검증, 서버 설치·실행·업데이트와 실행 파일 백업을 지원합니다. Forge·NeoForge 제작 모드는 mods 폴더로 연결됩니다.
- **참가자 게임 시작**: ‘게임 시작 · 자동 적용’을 누르면 최신 승인 배포의 모드와 선택한 공용 설정을 검증·백업·적용한 뒤 런처를 엽니다. 적용에 실패하거나 게임 실행 중이면 시작을 중단합니다. 런처에서 연결한 프로필의 플레이를 눌러주세요. 프로필 바로가기도 연결할 수 있습니다.
- **배포 승인 · 촬영 모드**: 기본 정책은 변경분 준비 → 메타데이터 검사 → 승인 배포입니다. 추가·교체·제거 목록을 확인할 수 있으며 촬영 모드는 현재 배포를 재시작 후에도 고정합니다. 검사 통과 시 자동 배포도 선택할 수 있습니다.
- **준비 현황**: 참가자 표시 이름, 적용 상태와 배포 버전을 보고하며 연결이 끊기면 준비 완료에서 제외합니다.
- **모드 검사**: Fabric / Forge / NeoForge 메타데이터에서 게임·로더·필수 의존성·중복 ID·충돌을 검사합니다. 실제 게임 실행 호환성은 촬영 전에 확인하세요.
- **이전 배포 복원**: 승인 배포 기록에서 복원하면 참가자의 다음 게임 시작에 적용됩니다. 복원 후 정책은 승인 모드로 전환합니다.
- **런처 프로필 · 공용 설정**: 공식 런처, CurseForge, Modrinth 프로필 검색과 폴더 직접 선택을 지원합니다. 알려진 환경 불일치는 차단합니다. 지정한 config 파일만 공유하며 키 설정·계정·토큰 파일은 제외합니다.
- **초대 · 고정 주소**: 초대 재발급·중지로 기존 연결을 만료시킬 수 있습니다. Cloudflare 고정 터널 토큰 또는 기존 HTTPS 프록시를 설정할 수 있습니다. 도메인·공개 호스트는 호스트 계정에서 준비하세요.

호스트와 참가자 모두 1.9.0 이상을 사용하세요. 설치된 앱은 업데이트를 자동 다운로드하며 재시작 또는 완전 종료 시 설치합니다.
